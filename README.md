# 🎤 MYPASS

> **공부한 지식을, 면접에서 설명할 수 있도록.**

프로젝트·이력서 등의 정보를 기반으로 사용자의 전공 및 프로젝트 경험에 맞는 질문을 생성하고, 실제 면접처럼 질문 → 답변 → 꼬리질문 → 평가 및 피드백까지 제공하는 **AI 기반 모의면접 웹 서비스**입니다.

---

## 📌 프로젝트 소개

기존의 AI 면접 서비스는 정해진 질문에 답하거나 단순한 면접 질문을 제공하는 경우가 많습니다.

MYPASS는 사용자가 직접 업로드한 **이력서 및 프로젝트 자료를 기반으로 개인화된 면접**을 제공합니다.

사용자의 프로젝트에서 사용한 기술과 구현 내용을 파악하고,

> **"이 프로젝트를 실제 면접관이 본다면 무엇을 물어볼까?"**

라는 관점에서 질문을 생성합니다.

또한 사용자의 답변을 분석하여 부족한 부분을 파악하고, 답변에 따라 **꼬리질문을 생성**하여 실제 면접과 유사한 경험을 제공합니다.

---

# 🎯 프로젝트 목적

### 1. 단순 암기가 아닌 설명 능력 향상

전공지식을 알고 있는 것과 면접에서 설명할 수 있는 것은 다릅니다.

MYPASS는 사용자가 자신의 프로젝트와 전공지식을 직접 설명하도록 하여 **실제 면접 대응 능력**을 향상시키는 것을 목표로 합니다.

### 2. 개인화된 면접 경험 제공

사용자가 업로드한 프로젝트와 이력서의 내용을 기반으로 질문을 생성하여 모든 사용자에게 동일한 질문이 아닌 **개인 맞춤형 면접**을 제공합니다.

### 3. 실제 면접과 유사한 상호작용

단순히 질문 목록을 제공하는 것이 아니라,

```text
질문
 ↓
사용자 답변
 ↓
답변 분석
 ↓
꼬리질문
 ↓
추가 답변
 ↓
최종 평가
```

와 같은 흐름으로 실제 면접과 유사한 경험을 제공합니다.

# 💡 MYPASS의 차별점

| 기존 AI 면접   | MYPASS           |
| ---------- | ---------------- |
| 정해진 질문 중심  | 사용자 프로젝트 기반 질문   |
| 일반적인 면접 질문 | 전공·직무·프로젝트 맞춤 질문 |
| 질문 → 답변    | 질문 → 답변 → 꼬리질문   |
| 단순 점수 제공   | 답변 내용 기반 분석      |
| 결과 확인 중심   | 부족한 지식 및 개선점 제공  |
| 텍스트 중심     | 음성·영상 면접으로 확장 가능 |

### 핵심 차별점

**① 프로젝트 기반 개인화**

사용자가 제출한 프로젝트의 기술 스택과 구현 내용을 분석하여 질문을 생성합니다.

**② 꼬리질문 기반 인터뷰**

사용자의 답변 내용에 따라 다음 질문이 달라지는 인터랙티브한 면접을 제공합니다.

**③ 지식 및 답변 분석**

단순히 정답 여부만 판단하는 것이 아니라 답변의 정확성, 구체성, 논리성 등을 분석합니다.

**④ 멀티모달 면접 확장**

향후 STT, TTS, 웹캠 및 시선·얼굴 방향 등의 데이터를 활용하여 실제 면접 환경에 가까운 서비스로 확장합니다.

**핵심 AI 면접 경험을 먼저 완성**.

### MVP 핵심 기능

```text
회원가입 / 로그인
       ↓
프로젝트 정보 입력
       ↓
PDF 업로드
       ↓
문서 텍스트 추출 및 전처리

       ↓
사용자 답변

답변 분석
       ↓
꼬리질문
       ↓
최종 평가 및 피드백
```

* 음성 및 영상 분석은 후순위로 개발합니다.

# 🔄 서비스 사용자 흐름

### 1. 회원가입 / 로그인

사용자가 계정을 생성하고 로그인합니다.

### 2. 프로젝트 등록

사용자가 프로젝트 정보를 입력합니다.

예시:

```text
프로젝트명
프로젝트 설명
사용 기술
담당 역할
주요 기능
문제 해결 경험
```

### 3. 자료 업로드

이력서 또는 프로젝트 관련 PDF를 업로드합니다.

### 4. 문서 처리

Backend + AI/RAG에서 업로드된 문서를 처리합니다.

```text
PDF
 ↓
텍스트 추출
 ↓
불필요한 내용 제거
 ↓
문서 분할
 ↓
프로젝트 정보 추출
 ↓
RAG 검색 구조 생성
```

### 5. AI 면접

분석된 프로젝트 정보를 기반으로 AI가 질문을 생성합니다.

```text
프로젝트 정보
     ↓
기술 스택
     ↓
구현 내용
     ↓
AI 질문 생성
```

### 6. 답변 및 꼬리질문

사용자의 답변을 분석하여 필요한 경우 추가 질문을 생성합니다.

```text
AI 질문
 ↓
사용자 답변
 ↓
답변 분석
 ↓
부족한 부분 / 추가 확인 필요
 ↓
꼬리질문
```

### 7. 최종 결과

면접이 종료되면 AI가 전체 답변을 분석하여 결과를 제공합니다.

예시:

* 답변 정확성
* 논리성
* 구체성
* 기술 이해도
* 부족한 부분
* 개선 방향
* 추가 학습이 필요한 기술

# 🧠 AI / RAG 데이터 흐름

MYPASS의 핵심은 **사용자가 제공한 프로젝트 데이터를 AI 면접에 활용하는 것**입니다.

```text
                사용자 파일
                    │
                    ▼
              PDF 텍스트 추출
                    │
                    ▼
              문서 전처리
                    │
                    ▼
             Chunking / 분할
                    │
                    ▼
          프로젝트 정보 / 기술 스택
                    │
                    ▼
             RAG 데이터 저장
                    │
                    ▼
              관련 정보 검색
                    │
                    ▼
                 LLM
                    │
          ┌─────────┴─────────┐
          ▼                   ▼
      질문 생성             답변 분석
          │                   │
          └─────────┬─────────┘
                    ▼
                꼬리질문
                    │
                    ▼
                최종 평가
                    │
                    ▼
                 피드백
```

> RAG 저장 방식은 MVP 구현 과정에서 결정하며, 초기에는 MariaDB 기반 구조를 활용하고 필요할 경우 별도의 Vector DB 도입을 검토합니다.

# 🎯 최종 목표

MYPASS는 단순한 AI 질문 생성 서비스가 아니라,

> **사용자의 프로젝트와 전공지식을 이해하고, 실제 면접관처럼 질문하고, 답변에 따라 추가 질문을 하며, 면접이 끝난 후 부족한 부분까지 분석해주는 AI 면접 플랫폼**

을 목표로 합니다.

최종적으로는

```text
프로젝트 자료
      ↓
사용자 이해
      ↓
개인화된 질문
      ↓
실제 면접
      ↓
답변 분석
      ↓
꼬리질문
      ↓
면접 평가
      ↓
약점 분석
      ↓
개선 방향 제시
```

까지 연결되는 **개인 맞춤형 AI 모의면접 플랫폼**을 구축합니다.
